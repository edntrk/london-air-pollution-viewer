# london-air-pollution-viewer
Interactive JavaFX application for visualising and comparing UK air pollution data across cities and years.

Overview:
Academic group project focused on air pollution data visualisation using Java and JavaFX. The application allows users to explore pollution trends, compare yearly statistics, and interact with geographic pollution overlays through an interactive desktop interface.

Features:
Interactive pollution data visualisation
Year-to-year comparison panels and statistics
Dynamic line and bar charts
Geographic pollution overlays and tooltip layers
JavaFX-based graphical user interface

Technologies Used:
Java
JavaFX
Object-Oriented Programming (OOP)

Notes:
Large air pollution datasets are not included in this repository due to file size limitations.
